# 🏛️ अमरावती महानगरपालिका — ई-गव्हर्नन्स प्रणाली

React (Vite) + Node.js (Express) — कर्मचारी, वॉर्ड अधिकारी व आयुक्तांसाठी एकत्रित सॉफ्टवेअर. संपूर्ण इंटरफेस मराठीत.

## चालू करा

गरज: **Node.js 22.13+** (built-in SQLite वापरतो, वेगळा DB server लागत नाही).

```bash
npm run install:all
cp server/.env.example server/.env      # JWT_SECRET व DATA_ENCRYPTION_KEY बदला
npm run dev:server                       # API → http://localhost:5000  (पहिल्यांदा demo डेटा आपोआप भरतो)
npm run dev:client                       # App → http://localhost:5173
```

Production: `npm run build && npm start` — Node server स्वतः `client/dist` सर्व्ह करतो (एकच port 5000).
Demo डेटा पुन्हा भरायचा असल्यास: `npm run seed` (सर्व डेटा पुसला जातो).

## फीचर्स

**कर्मचारी (मोबाईल app)**
- मोठे आयकॉन, कमी मजकूर, खालच्या बाजूला नेव्हिगेशन
- **Geo-fenced सेल्फी हजेरी** — वॉर्डच्या केंद्रापासून ठरलेल्या त्रिज्येत. `GEOFENCE_MODE=strict` असल्यास बाहेरून हजेरी नाकारली जाते, `warn` असल्यास घेतली जाते पण अहवालात ⚠️ दिसते
- **Before / After फोटो पुरावा** — फोटोवर Live GPS + तारीख/वेळ watermark आपोआप
- **Offline mode** — नेटवर्क नसताना हजेरी व फोटो फोनमध्ये (IndexedDB) सेव्ह, नेटवर्क आल्यावर आपोआप Sync; कामांची यादी cache मधून दिसते

**वॉर्ड अधिकारी / सुपरवायझर**
- **Auto-routing** — तक्रारीच्या GPS वरून जवळचा वॉर्ड → प्रकारावरून विभाग → त्या वॉर्डचा अधिकारी + आज हजर व सर्वात कमी काम असलेला कर्मचारी
- **Role-based access** — अधिकाऱ्याला फक्त त्यांचा विभाग/प्रभाग दिसतो (server-side फिल्टर)
- **SLA व Escalation** — प्रत्येक प्रकाराला वेळ मर्यादा; उशीर झाल्यास स्तर १ (वॉर्ड अधिकारी) → स्तर २ (विभाग प्रमुख) → स्तर ३ (आयुक्त), App + WhatsApp सूचना
- **डिजिटल मंजुरी** — जन्म/मृत्यू दाखला, बांधकाम/व्यापार परवाना, नळ जोडणी; मोबाईलवर सही करून एका क्लिकवर मंजूर. दाखल्यावर QR + SHA-256 हॅश — `/verify` वर कोणीही खरेपणा तपासू शकतो
- हजेरी अहवाल (सेल्फीसह, CSV export), तक्रारी नकाशावर

**आयुक्त / Admin**
- **Command Center डॅशबोर्ड** — प्रलंबित/उशीर तक्रारी, SLA पालन %, आज हजर, कचरा (टन), कर संकलन, वाहने, अडकलेल्या फाईल्स; दर मिनिटाला अपडेट
- **ई-ऑफिस फाईल ट्रॅकिंग** — फाईल कोणाकडे, किती दिवसांपासून; प्रत्येक टेबलवर किती तास राहिली
- **वाहन ट्रॅकिंग** — Live GPS नकाशा, १२ तासांचा मार्ग, इंधन नोंद व खर्च, कचरा फेरी वजन
- कर्मचारी व्यवस्थापन, वॉर्ड Geo-fence सेटिंग, SLA तास बदलणे

**सुरक्षा व तांत्रिक**
- नागरिकांचे मोबाईल नंबर **AES-256-GCM** ने encrypted (कर्मचाऱ्याला masked दिसतो)
- JWT login, bcrypt पासवर्ड, login rate-limit, helmet, audit log
- **दररोज आपोआप DB backup** (`server/backups/`, १४ दिवस) — cloud साठी हा फोल्डर S3/Drive वर sync करा
- प्रत्येक मॉड्युल (`server/src/modules/*.js`) स्वतंत्र — पुढे वेगळ्या microservice मध्ये हलवता येईल

- **भाषा:** मराठी / English / हिंदी. Header मधील भाषा बटण वापरा; निवड लक्षात ठेवली जाते. भाषांतरे `client/src/i18n/dict/*.js` मध्ये आहेत. नवीन मजकूर `t('मराठी मजकूर')` ने लिहा आणि त्याचे en/hi भाषांतर dict मध्ये जोडा. आवाजाने लिहिणे (voice input) निवडलेल्या भाषेत चालते. डेटा (नावे, पत्ते, कर्मचाऱ्यांनी लिहिलेला मजकूर) ज्या भाषेत नोंदवला त्याच भाषेत दिसतो.
- **भूमिकेनुसार डॅशबोर्ड:**
  - **आयुक्त:** आजचे व वर्षभराचे कर संकलन (मालमत्ता + पाणीपट्टी), तक्रार निराकरण दर, ७ दिवसांपेक्षा जास्त अडकलेल्या फाईल्स, ऑन-ड्युटी कर्मचारी, SLA भंग व आपत्कालीन अलर्ट, GIS नकाशा (प्रभागावर क्लिक), प्रभागनिहाय कामगिरी, अर्थसंकल्प विरुद्ध खर्च.
  - **अधिकारी:** नेमणूक बाकी, मंजुरी, आजच्या तपासणी भेटी, आज मुदत संपणारी कामे, कर्मचारी व वाहनांचा लाईव्ह नकाशा, Quick Actions.
- **नवीन पाने:** काम फलक (Kanban, एकत्रित बंद), ड्युटी रोस्टर व लाईव्ह लोकेशन (काम हस्तांतरण), तपासणी भेटी, आपत्कालीन व्यवस्थापन, बजेट व खर्च, अग्रीम / कर्ज अर्ज (पगारातून हप्ता कपात), एकत्रित e-Sign मंजुरी.
- **चेहरा ओळख हजेरी:** `@vladmandic/face-api`, मोबाईलवरच चालते. पहिल्या हजेरीला चेहरा नोंदवला जातो, नंतर प्रत्येक हजेरीला तुलना होते. `FACE_MODE=strict` असल्यास न जुळलेली हजेरी नाकारली जाते; default `warn` मध्ये ती घेतली जाते व flag होते.
- **Live updates (WebSocket / socket.io):** नवीन तक्रार, अलर्ट, सूचना पान refresh न करता दिसतात.
- **Export:** प्रत्येक यादी व विजेट CSV / Excel (.xlsx) / PDF मध्ये.
- **WhatsApp:** कर्मचाऱ्याच्या नवीन कामाच्या मेसेजमध्ये फोटो व Google Maps लिंक असते. रजा, अग्रीम व साहित्य मागणी यांचीही एका-क्लिक मंजुरी WhatsApp वरून होते.

| **मालमत्ता कर** — मालमत्ता नोंद, वार्षिक आकारणी, ५% लवकर-भरणा सवलत, २%/महिना दंड, काउंटर भरणा व पावती, नागरिक थकबाकी पान `/pay-tax` | `server/src/modules/tax.js` |
| **प्रभाग हद्द (polygon)** — Admin → वॉर्ड Geo-fence मध्ये GeoJSON हद्द दिल्यास हजेरी व तक्रारीचा वॉर्ड त्यावरून ठरतो | `server/src/utils/geo.js` |

**GPS demo:** `npm run simulate --prefix server` चालवा. ६ कचरा गाड्या नकाशावर फिरतात आणि त्यातली एक मुद्दाम मार्ग सोडते, त्यामुळे वाहन ट्रॅकिंग पानावर अलर्ट येतो.

**PostgreSQL + PostGIS:** तुमच्या database design नुसार production schema `server/schema/postgres.sql` मध्ये आहे (PostGIS GIST index, GPS/log tables वर महिन्यानुसार partitioning, JSONB, soft delete, updated_at triggers). सध्याचे app SQLite वरच चालते; PostgreSQL वर नेण्यासाठी `db.js` चा data layer async `pg` मध्ये बदलावा लागेल.

## Integrations (कॉन्फिगरेशन)

- **WhatsApp**: `.env` मध्ये `WHATSAPP_TOKEN` व `WHATSAPP_PHONE_NUMBER_ID` (Meta Cloud API) भरा. रिकामे असल्यास मेसेज server console मध्ये दिसतात. Business-initiated मेसेजसाठी Meta ने मंजूर केलेले template लागतील — `server/src/utils/notify.js` मध्ये बदल करा.
- **वाहन GPS डिव्हाइस**: `POST /api/fleet/ping` header `x-device-key: <key>` body `{ "lat", "lng", "speed" }`. नवीन वाहन तयार केल्यावर key मिळते.

## पुढील टप्पे (अजून नाहीत)

- **Face Recognition** — सध्या सेल्फी फोटो साठवला जातो व अधिकारी अहवालात पाहतात; आपोआप चेहरा जुळवणे (उदा. face-api.js / AWS Rekognition) बाकी
- **Aadhaar e-Sign / DSC** — सध्या canvas सही + SHA-256 हॅश; कायदेशीर e-Sign साठी ESP (eMudhra/NSDL) integration लागेल
- SMS gateway, ऑनलाइन कर भरणा (Razorpay/BillDesk payment gateway — `tax.js` मधील pay फंक्शन webhook मधून वापरता येईल)
- WhatsApp business-initiated मेसेजसाठी Meta-approved templates
- मोठ्या प्रमाणासाठी SQLite ऐवजी PostgreSQL/MySQL (SQL साधे ठेवले आहे)
